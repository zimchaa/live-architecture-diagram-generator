# Live Architecture Diagram Generator

  A static HTML/CSS/JS tool that generates PlantUML, C4, and Mermaid diagrams from JSON architecture definitions.

  ## Features
  - JSON schema validation
  - Component PUML diagrams
  - C4 PUML diagrams  
  - Mermaid diagrams
  - Pan/zoom on previews
  - PNG, SVG, and clipboard export
  - Pop-out modal view
  - Responsive layout

  ## Usage
  Open `index.html` in any modern browser or serve with a static file server.

  ## CDN Dependencies
  - AJV 8.17.1 (JSON validation)
  - Mermaid 11.5.0 (diagram rendering)
  - Pako 2.1.0 (PlantUML encoding)
